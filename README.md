# BThinkX Product Management System

A simple e-commerce product management system built as part of the Junior Python/Django Developer Development Test.

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap 5
- JavaScript

## Features

- User login and logout
- Dashboard with product statistics
- Product CRUD operations
- Product search
- Category filtering
- Active/Inactive filtering
- Pagination
- Product image upload
- Product validation
- SKU uniqueness validation
- Low stock indication
- Delete confirmation
- Authentication-protected product management
